# NOTICE

Chile State Institutional Map is an independent analytical dataset authored by Sebastián Elgueta Godoy.

## Public-source evidence

The repository uses names, institutional structures, directories and other factual material drawn from official public sources. Those source materials remain attributable to their original institutions.

The normalized schema, analytical identifiers, coverage model, supplements, provenance structure and repository documentation are project work. Public availability does **not** imply ownership over official source material or a blanket relicensing of third-party content.

## Literal snapshots

Files explicitly described as literal official snapshots are preserved for provenance and should not be interpreted as project-authored institutional text.

## Citation

Use `CITATION.cff`, `CITATION.bib` or the version DOI for the dataset and cite original institutional sources when using source-specific facts.
